## Base URL

```
https://api.nzochain.com/api
```

Todas as rotas abaixo são relativas a este prefixo. **Não** uses `https://api.nzochain.com/v1` sem `/api`.

## Duas camadas

| Camada | Prefix | Uso |
|---|---|---|
| **API v1 Firewall** (recomendada para produtos novos) | `/v1/...` | Contrato estável: `decision`, `riskLevel`, `reasons` |
| Legado | `/risk/scan`, simulação, etc. | Continua a existir; a app B2C e integrações antigas usam-no |

Começa por [API v1](/api/v1) e o [Quickstart REST](/quickstart). Autenticação: [X-API-Key](/api/authentication).

**Sem SDK oficial:** não existe pacote npm `@nzochain/sdk` publicado. Integra com HTTP (`curl` / `fetch`).

## Redes

Endpoints de risco cobrem **quatro** redes EVM: Ethereum, BNB Chain, Polygon, Arbitrum. **Solana não é suportada.**

## Rate limits e quotas (live)

A API aplica, em produção:

| Camada | O que faz |
|---|---|
| **Global** | Throttling Nest / middleware por IP e carga |
| **Per-path** | Caps específicos (ex.: scan, login, forensic) |
| **Per-key** | Free: **hard cap** (`429 RATE_LIMIT`). Pagos: **overage faturado** até **3×** a quota, depois `429 HARD_CEILING`. |

Alertas de consumo 80%/100% ao dono da conta (quando o serviço de quota-alert está activo); admin Telegram na 1.ª entrada em overage nos planos pagos.  
Quotas de **simulação** bloqueiam com `403 SIMULATION_QUOTA`. Ver [erros](/api/errors).

**Nota:** um `429` de quota mensal **não** significa que a API Key expirou. Expiração (`expiresAt`) e revogação são estados separados da key.

## Planos e volume

| Plano | Calls / mês | Firewall | Simulate / mês | Threats | Overage / call |
|---|---|---|---|---|---|
| Free | 1 000 | Não | 0 | Não | **Hard cap** (sem overage pago; `429 RATE_LIMIT`) |
| Starter | 25 000 | Sim | 100 | Não | $0.004 (até 3×; depois `HARD_CEILING`) |
| Growth | 100 000 | Sim | 2 000 | Standard | $0.002 (até 3×; depois `HARD_CEILING`) |
| Business | 500 000 | Sim | 10 000 | Completo | $0.001 (até 3×; depois `HARD_CEILING`) |
| Enterprise | Contrato (pilot-grade) | Sim | Contrato | Completo | Contrato |

## Simulação

Simulação **live** exige Tenderly configurado. Sem Tenderly (ou se a chamada live falhar), a resposta é análise **estática / degradada**.

## Webhooks

Evento live: **`revocation.completed` apenas**. Outros eventos estão em roadmap. Ver [Webhooks](/api/webhooks).

## Envelope JSON

Respostas de sucesso (interceptor):

```json
{ "success": true, "data": { } }
```

`data` na v1 inclui tipicamente `riskScore`, `riskLevel`, `decision`, `reasons`.
