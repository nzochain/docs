<Warning>
  **Deprecated.** There is no production `GET /api/wallet/monitor` endpoint.
  Legacy `/api/wallet/*` routes return **HTTP 410 Gone**. Use the API v1 firewall instead.
</Warning>

## Replacement

```
POST https://api.nzochain.com/api/v1/wallets/risk
Header: X-API-Key: pk_live_...
Body: { "wallet": "0x...", "network": "ethereum" }
```

See [API v1](/api/v1) and [authentication](/api/authentication).

For multi-network approval inventory (legacy live surface, not under `/wallet`):

```
POST https://api.nzochain.com/api/risk/scan-all
```

## Why this page changed

Older drafts documented `/api/wallet/monitor` as continuous / real-time monitoring. That path was never a real production controller. Product monitoring today is **opt-in scheduled re-scan every 6 hours** in the B2C app (**off by default**; not guaranteed for every user) — not mempool or event-driven continuous monitoring, and **not** exposed as a public `/api/wallet/*` API.
