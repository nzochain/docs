<Warning>
  **Not a live production endpoint.** There is no supported public bulk-scan API that accepts Solana or arbitrary multi-chain batches.
  Prefer **[POST /api/v1/wallets/risk](/api/v1)** (one EVM wallet per call) on Ethereum, BNB Chain, Polygon, or Arbitrum.
  Do **not** call legacy `/api/wallet/*` (HTTP 410 Gone).
</Warning>

## What to use instead

```
POST https://api.nzochain.com/api/v1/wallets/risk
Header: X-API-Key: pk_live_...
Body: { "wallet": "0x...", "network": "ethereum" }
```

`network`: `ethereum` | `bnb` | `polygon` | `arbitrum` only.

**Solana is not supported.** Do not submit Solana addresses to risk APIs.

For many wallets, call `POST /api/v1/wallets/risk` per address (respect [rate limits and monthly quotas](/api/overview)) and cache results client-side.

## Historical note

Older drafts documented `POST /api/bulk/scan` with up to 1,000 addresses including Solana. That surface is **not** part of the current production contract. Treat any remaining `/api/bulk/scan` references as outdated.
