Expõe os planos **B2C activos** para checkout, pricing e integrações que precisam dos limites oficiais. Não requer autenticação.

## Endpoints

| Método | Path | Descrição |
|--------|------|-----------|
| `GET` | `/api/plans` | Lista planos B2C activos |
| `GET` | `/api/plans/:slug` | Um plano por `slug` |

Base: `https://api.nzochain.com/api`

## Forma da resposta (contrato pretendido)

Cada plano inclui, entre outros, os campos:

`id`, `slug`, `name`, `type`, `active`, `price`, `periodDays`, `scanLimit`, `apiLimit`, `walletLimit`, `contractScanLimit`, **`simulationLimit`**, `features`, `createdAt`.

## Uso consumido vs limite

`GET /api/plans` devolve apenas os **limites do catálogo**, não o teu consumo.

Na app autenticada, `GET /api/subscriptions/my` devolve `{ subscription, usage }` (JWT obrigatório). O objecto `subscription.plan` inclui **`simulationLimit`**; o objecto `usage` inclui **`simulationsUsed`**. O dashboard mostra simulações **restantes** ≈ limite menos consumo no período de facturação.

Para quotas B2B de simulação na API, vê [API v1](/api/v1) e [planos Enterprise](/pricing/enterprise).
