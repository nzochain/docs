<Warning>
  **Currently supported:** `revocation.completed` only.
  **Roadmap (not live):** `wallet.scan.completed`, `risk.alert`.
  There is no production dispatcher for other event names. Do not treat B2C email/push/Telegram alerts as B2B webhooks.
</Warning>

Manage subscriptions in the [Developer Portal](https://developers.nzochain.com/webhooks) (UI recomendada) or via the developer session API:

```
POST https://api.nzochain.com/api/developer/projects/:projectId/webhooks
Cookie / session JWT do portal (não uses X-API-Key nesta rota de gestão)
Body: { "url": "https://your-app.com/hooks", "events": ["revocation.completed"] }
```

A **API key** (`X-API-Key`) autentica chamadas `/v1/...`. A **sessão do portal** gere projectos/webhooks. Não mistures os dois contratos.

## Event: `revocation.completed`

Fired when an approval revocation is confirmed on-chain.

Headers:
- `X-NZOChain-Signature: sha256=<hmac>`
- `X-NZOChain-Event: revocation.completed`

```json
{
  "event": "revocation.completed",
  "timestamp": "2026-09-15T18:00:00.000Z",
  "data": {
    "wallet": "0x…",
    "network": "ethereum",
    "spender": "0x…",
    "dappName": null,
    "symbol": "USDT",
    "txHash": "0x…",
    "revokedAt": "2026-09-15T18:00:00.000Z"
  }
}
```

## Verifying authenticity

HMAC-SHA256 of the **raw JSON body** with your `whsec_*` secret. Compare to `X-NZOChain-Signature` (prefix `sha256=`).

## Delivery

- HTTPS only (SSRF protections apply)
- Retries: 1s → 5s → 30s
- Expect HTTP 2xx; non-2xx marks the webhook as failing after retries

Full details: backend `docs/WEBHOOKS.md`.
