## A NZOChain consegue mover os meus fundos?

**Não.** Nunca temos chaves nem seed. Só tu assinas. A ferramenta ajuda a **revogar permissões**; nunca envia tokens por ti.

## O que é uma aprovação e porque é perigosa?

É uma autorização para um contrato gastar os teus tokens. Muitas são **ilimitadas** e ficam para sempre. Se o contrato ou o site for comprometido, podem esvaziar esse token **sem nova assinatura**.

## O que faço se já assinei algo suspeito?

Corre um scan, vê o que está activo e revoga o perigoso. A simulação (live via Tenderly, senão estática/degradada) ajuda a não repetir o erro na próxima assinatura. Na app: modo “Fui hackeado” / forensic para **timeline heurística e advisory** — nunca prova definitiva. 

## Quantas blockchains estão suportadas?

**Quatro** EVM no produto de scan: Ethereum, BNB Chain, Polygon, Arbitrum. **Solana não é suportada.** Ver [Redes](/networks/overview).

## A monitorização é em tempo real?

**Não.** É **opt-in**, com re-scan agendado a cada **6 horas**. Não há mempool nem monitorização contínua event-driven.

## Quais são os planos B2C?

Free ($0, 1 wallet), Basic ($4.99, 3), Pro ($9.99, 10), Premium ($19.99, 50). Monitorização opt-in (cron 6h) nos planos. Scans/contratos são limites técnicos. Anual = 2 meses grátis. [Tabela](/pricing/individual).

## Quais são os planos B2B?

Free (1 000 calls, **hard cap** `429 RATE_LIMIT`, **sem** Firewall) → Starter $49 (overage $0.004 até 3×) → Growth $149 ($0.002) → Business $499 ($0.001) → Enterprise **pilot-grade** (contrato; sem “unlimited” / SLA 99.9% no catálogo público). Sem SSO/VPC/SLA 99.9 no catálogo actual. [Matriz](/pricing/enterprise).

## A API bloqueia quando passo o limite de calls?

**Depende do plano.**

| Plano | Comportamento |
|---|---|
| **Free** | Hard cap → `429 RATE_LIMIT` ao atingir a quota (1 000) |
| **Starter / Growth / Business** | Soft: overage faturado no ciclo; bloqueio só acima de **3×** a quota → `429 HARD_CEILING` |
| **Enterprise** | Sem teto público (custom) |

Alertas ao dono da key aos **80%** e **100%** (email). Admin (Telegram) quando a key entra em overage. Também existem throttles **globais** e **por path**. Simulações: `403 SIMULATION_QUOTA`. Features fora do plano: `403 PLAN_UPGRADE_REQUIRED`.

## Como autentico a API?

Header `X-API-Key` com a chave do [portal](https://developers.nzochain.com). Base: `https://api.nzochain.com/api`. Não uses Bearer nas rotas B2B actuais. **Não existe SDK oficial publicado** — integra via REST (`curl` / `fetch`). Ver [Quickstart](/quickstart).

## Que webhooks existem?

Só **`revocation.completed`** está live. Outros eventos (ex. `wallet.scan.completed`, `risk.alert`) estão em roadmap. Ver [Webhooks](/api/webhooks).

## A NZOChain pede seed?

Nunca. Login B2C = ligar wallet + assinar mensagem.
